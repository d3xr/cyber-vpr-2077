**Owner:** PM
**Stakeholder:** Кирилл (lead investor, мем-канон bash.org #135295)
**Статус:** v1.0 — Approved for build
**SLA:** ≤ 730 дней (заказчик ждёт джва года)

---

## 1. Контекст

Стратегический инвестор Кирилл сформулировал ТЗ в свободной форме, но в списке требований не идёт на компромиссы. Прямой отказ → потеря funding. Полная реализация в виде нового продукта (3D-RPG уровня Daggerfall) → бюджет ×500.

**Решение:** реализуем **secret easter-egg level** внутри текущего веб-приложения. Активация скрытая — основной аудитории (4-классники + родители) контент невидим, демо для Кирилла проходит на ура.

Принцип: **буква ТЗ соблюдена 1-в-1, дух — остроумно переинтерпретирован под web-стек**.

**Нарратив-крюк (для органичности с основным приложением):**
В Cyberpunk 2077 каноничный лор — DataKrash 2023, после которого старый Net разделён на безопасный и опасный (Old Net). V (игрок) через канал 077 натыкается на legacy-сервер 2006 года: забытый MMORPG-проект некоего Кирилла, висящий в Old Net уже джва года. Войти можно только через консольный чит. Это объясняет резкую смену эстетики (киберпанк → ретро-фэнтези 2006) и делает уровень частью лора, а не «инородным телом».

## 3. Активация скрытого уровня

Три равнозначных триггера (даём избыточность, чтобы Кирилл точно нашёл):

1. **Konami-код** на стартовом экране Briefing: `↑ ↑ ↓ ↓ ← → ← → B A`
2. **«джва»**: семь кликов по логотипу CYBER VPR подряд за ≤3 сек
3. **Текстовый чит:** ввод `korovan` в поле CALLSIGN

При активации:
- В zustand: `gameStore.korovan.active = true`, persist в localStorage
- Глобальный CSS-класс `body.korovan-mode` → переключает скин (Times New Roman, бежевый пергамент, кринж-эстетика 2006)
- Начинается глитч-переход: cyberpunk-glitch → matrix rain → fade-in пергамента

**Защита от случайной активации детьми:** confirm-диалог «Ты нашёл OLD-NET архив 2006. Войти? Этот режим — для очень странных инвесторов.» При отмене флаг не ставится.

## 4. Объём фич по приоритетам

### P0 — без этого Кирилл не подпишет
- Корованы и их грабёж
- 4 зоны с 3 фракциями
- Расчленёнка (рука/глаз/нога) с протезами
- LOD деревьев (вдали emoji → вблизи 3D)
- Сохранения
- Финальный экран «джва года»

### P1 — желательно
- Магазин Daggerfall-style
- Прыжки
- Набеги других фракций
- Свободный режим за злого

### P2 — если останется время
- Озвучка криков «НАБИГАЮТ» через Web Speech API (он уже подключён в Mission1)
- Ambient звук леса через Web Audio API (тоже уже есть)
- Опечатки Кирилла как фичеры в UI (эстетика канона — ОБЯЗАТЕЛЬНО)

### Out of scope (явно НЕ делаем)
- Реальный 3D-движок (Three.js, Babylon, Unity) — только CSS-perspective
- Сетевой режим / мультиплеер
- Реалистичная анатомия — только emoji/ASCII
- Локализация — только русский (Кирилл писал на нём)
- Mobile — desktop only (Konami-код требует клавиатуру)

## 5. Технические решения

**Файлы для изменения:**
- `src/types.ts` — добавить `Stage = ... | 'korovan'`, `KorovanState`, `BodyState`, `KorovanItem`
- `src/store/gameStore.ts` — добавить ветку state `korovan`, actions, bump persist version → 6
- `src/screens/KorovanIntro.tsx` — глитч-переход cyber → fantasy
- `src/screens/KorovanLevel.tsx` — главный экран уровня
- `src/components/korovan/` — `<Tree2D/3D>`, `<Korovan>`, `<BodyHUD>`, `<DaggerfallShop>`, `<EvilFinale>`
- `src/utils/useKonami.ts` — хук для Konami-кода
- `src/index.css` — секция `.korovan-mode` со всеми стилями ретро-RPG
- `src/App.tsx` — роутинг + window-level Konami listener + клик-секрет на logo в Briefing
- Никаких новых зависимостей. Текущего стека (React + Tailwind + Framer + zustand + augmented-ui) достаточно.

**Псевдо-3D без WebGL:**
```css
.kor-tree-near {
  transform: perspective(400px) rotateY(15deg) rotateX(5deg);
  transform-style: preserve-3d;
}
```
Куб дерева = 4 div (ствол + 3 грани кроны). Performance — мизерный, держит 60fps на школьных Chromebook'ах.

**Расчленёнка:**
```ts
type BodyPart = 'leftArm' | 'rightArm' | 'leftEye' | 'rightEye' | 'leftLeg' | 'rightLeg' | 'torso';
type LimbState = 'ok' | 'wounded' | 'lost' | 'prosthetic';
```
HUD — пиктограмма человечка из символов, потерянные части перечёркиваются красным. Никаких текстур крови.
